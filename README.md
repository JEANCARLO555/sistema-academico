# Sistema Académico

## Descripción del Proyecto
Sistema desarrollado para la gestión académica, control de estudiantes, cursos y notas.

## Estructura del Proyecto
- `src/`: Código fuente de la aplicación.
- `docs/`: Documentación del proyecto.
- `README.md`: Descripción general del repositorio.

## Estrategia de Ramas (Branching)
- `main`: Rama principal con código estable.
- `develop`: Rama de desarrollo donde se integran las características.
- `feature/*`: Ramas secundarias para el desarrollo de funcionalidades específicas.
